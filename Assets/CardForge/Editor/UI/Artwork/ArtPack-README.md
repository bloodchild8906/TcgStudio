# CardForge Studio — Professional UI Art Pack

This pack includes 10 individually named PNG assets suitable for Unity UI Toolkit.

**Visual system:** deep navy and slate-blue surfaces, fine blueprint lines and restrained gold accents.

## Assets

- `CardForge_LogoMark.png` — isolated logo mark; RGBA, alpha background
- `CardForge_AppIcon.png` — square application icon
- `CardForge_UIBackground.png` — shared background
- `CardForge_LayoutDesigner_BG.png` — layout designer background
- `CardForge_CardDatabase_BG.png` — card database background
- `CardForge_BlockBuilder_BG.png` — block builder background
- `CardForge_TurnFlow_BG.png` — turn flow editor background
- `CardForge_ActionDesigner_BG.png` — action editor background
- `CardForge_AbilityDesigner_BG.png` — ability editor background
- `CardForge_IconWorkshop_BG.png` — icon workshop background

## Unity UI Toolkit guidance

Place these images under `Assets/CardForge/Editor/UI/Artwork/`. Use `Image` elements with `ScaleAndCrop`, and place a semi-opaque solid-color `VisualElement` layer above backgrounds where controls need extra contrast. Set icon texture types/sRGB appropriately for UI use. The backgrounds are intentionally atmospheric, not mockups of actual UI controls.
